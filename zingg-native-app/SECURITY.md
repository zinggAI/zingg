# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Zingg Entity Resolution and MDM, please report it to us privately.

- Email: contact@zingg.ai
- Subject: Security report, Zingg Entity Resolution and MDM

Please include a description of the issue, the steps to reproduce it, the app version you are using, and the impact you see.

## What to expect

We will acknowledge your report, investigate it, and keep you informed until it is resolved. If you would like to be credited for the finding, tell us in your report.

## Scope

This policy covers the Databricks App in this repository (the application source, `app.yaml` and `requirements.txt`) and the Zingg JAR that the app bundles.

## Supported versions

Security fixes are provided for the latest released version of the app.
